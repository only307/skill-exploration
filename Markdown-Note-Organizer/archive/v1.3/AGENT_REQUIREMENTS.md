# Agent 能力要求 · v1.3

本文件说明执行 [markdown笔记整理](SKILL.md) 所需的模型与工具能力。安装技能只加载规则，不自动赋予文件系统、附件解析、图像识别、下载生成或联网权限。无需固定模型品牌、平台或特定第三方依赖。

## 必要能力

| 能力 | 通常由谁提供 | 最低要求 |
| --- | --- | --- |
| 理解中文及 Markdown | 模型 | 区分正文、标题、表格、代码、公式、链接与图片引用 |
| 遵循选择与类型规则 | 模型 | 完整预读后合并确认输出、历史／时事、保存位置和参考改名；规范目标名，参考获准才改，最后执行 A/B/C/D；草稿、正式和大纲独立 |
| 整理知识与保持含义 | 模型 | 正式内容保留重点、必要写法与结构并筛选总结，大纲由模型归纳而不照搬；保留条件、否定、疑义，不凭空补事实 |
| 新旧内容对照 | 模型结合完整输入 | 区分重复、新细节和相互矛盾；更新时不删已有知识 |
| 获取完整来源与旧目标 | 用户提供全文，或附件／文件读取工具 | 完整读到必要内容，不能以截断预览代替全文 |
| 如实反馈结果 | 模型结合工具结果 | 不虚构写入成功、下载链接、已验证结论或已处理素材 |

上述能力缺失到无法保护原文或判断目标身份时，不能安全更新已有文件。应指出具体缺口并请求必要信息。

## 与执行条件相关的能力

| 条件 | 需要的能力／工具 | 缺失时的处理 |
| --- | --- | --- |
| 直接读取本地笔记 | 文件读取、目录查询、路径解析、编码处理 | 用户提供完整附件或全文；不可声称已读取不可访问路径 |
| 目标规范命名与参考可选改名 | 类型与主题识别、文件系统安全改名／移动、冲突检查、完整字节核对、路径映射更新 | 目标不能本地改名时可交付规范名完整结果；参考获准才改名／生成副本，拒绝则旧名读取继续；不能读全时暂停 |
| 更新已有文件 | 规范改名后在所选目录安全写入、文件身份判断、写前／写后重读 | 必要内容完整时自动降级为规范名的真实可下载文件；不继续使用旧名 |
| 保存位置决策 | 获取真实绝对路径、识别来源及旧目标目录、判断稳定性和可写性、向用户说明候选位置 | 路径不明时先询问并暂停最终写入；不得无声使用任务或缓存目录 |
| 集中确认 | 完整预读、识别文件角色、收集真实路径与未定项、记录明确选择 | 未回答不默认；拒绝参考改名不阻塞；只补问缺项或新问题 |
| 历史／时事内容范围 | 模型识别理工科任务、区分技术条件与背景、分别记录两类的保留选择 | 不确定项并入集中确认；未回答不筛选、改名或写最终笔记，预读可用隔离解析产物 |
| 中间产物清理 | 专用隔离临时目录、记录本次具体路径、准确删除和空目录检查 | 无法确认归属时不删；未能清理则列真实路径与原因，不声称已清理 |
| 无法本地写入后的文件交付 | 当前环境支持创建实际 `.md` 输出与可访问下载链接 | 不伪造链接；只可给明确标注的复制用文本，并说明文件交付未完成 |
| 已有文件安全更新 | 读取完整原文、保存候选、差异比较及可用的并发检查 | 无法完整核对则不覆盖；读全但不能在规范路径安全写入时生成下载版 |
| 两种笔记同时生成 | 分别准备、检查、写入和验证两个目标 | 按文件报告成功／失败，失败项尝试下载，不声称整体事务保证 |
| 图片或扫描页 | 模型视觉或 OCR，必要时图像渲染 | 请求可读文字或可识别版本；未完成前不声称完整导入 |
| PDF | 对应解析工具，扫描内容另需图像识别 | 提取可读取部分并指出缺口；核心信息缺失时等待必要补充 |
| Word／PPT | 对应格式解析，关键图表需要可视读取 | 可请求导出到当前环境支持的可读格式，不默认所有版本均可解析 |
| 复杂公式与数据图 | 公式／表格提取，或清晰图像结合模型理解 | 保留可辨识原貌及存疑标记，不推断缺失公式／数值 |
| 荧光效果验证 | 实际目标阅读器或渲染预览能力 | 按规定结构输出，声明未验证；发现禁用样式时说明限制并确认展示方式 |
| 改变输出目录且有相对图片引用 | 资源定位与有效路径处理；如需随附资源还要复制／交付能力 | 不制造失效引用的成功承诺；明确资源需另行提供或保存的位置 |

识别含糊与完全无法读取必须区分：前者保留可辨识内容并标记存疑；后者不能用猜测文本代替。加密、损坏、旧版或受限文档没有自动支持保证。

## 推荐增强能力

- 稳定的多文档、长上下文理解，或可分段遍历全文的工具，避免漏掉旧目标后半部分。
- 对公式、单位、否定词和边界条件的细致核对能力，减少误去重。
- 在全文中识别明确的同一学术／专业术语，落实正式笔记仅首次加粗，不因新增批次而重复标识。
- 区分有学习价值的原句、可总结的冗余信息与已有目标内容，避免整份素材照搬，也避免误删已有知识。
- 文件内容差异检查、哈希／修改状态检查、排他创建、可恢复写入等能力，用于减少覆盖风险；它们不能代替知识层面的核对。
- 可在实际阅读器预览 HTML、列表、公式和代码的能力，发现荧光块的兼容问题。
- 可追溯页码、幻灯片号、图片与文字对应关系，帮助用户定位存疑来源。

这些能力不要求安装额外的向量库、语义评分模型、知识数据库或统一自动化框架。没有联网工具不影响基于充分材料的整理。

## 各类环境能完成到什么程度

| 环境 | 可完成的范围 | 不能宣称的结果 |
| --- | --- | --- |
| 仅文本输入／输出 | 在提供完整文本后给出整理文本建议 | 本地文件已修改、已创建下载文件、已识别未呈现的图片 |
| 能读附件，不能写本地，能生成文件 | 读取完整内容后交付可下载正式／大纲 Markdown | 已自动更新用户原目录 |
| 能读附件，但既不能写本地也不能生成文件 | 分析和明确标识的文本建议 | 已完成文件交付 |
| 有本地读写能力 | 直接整理支持格式的来源并安全更新目标 | 未经检查的并发安全或跨文件原子保证 |
| 本地读写＋图像／文档解析 | 合并相应可读取素材并生成所选目标 | 对所有格式、扫描质量和阅读器的无条件兼容 |

当本地不可写但输入完整且具备文件生成能力时，应采用下载降级；事先说明不能直接保存到本地，交付时报告实际生成位置或真实平台标识／链接及规范文件名。若平台不暴露本地绝对路径，应说明，不得编造位置。文件名与旧内容保护要求不变。

## 何时必须暂停受影响操作

- 集中确认后输出类型仍未明确时暂停最终生成；预读不依赖该答案。
- 核心输入或已有目标无法完整读取，内容缺失或编码不能可靠还原。
- 目标与草稿／其他类型／无关文件冲突，或无法确认实际应该修改哪个文件。
- 任何已识别笔记的规范名称被另一文件占用，或主题／类型无法安全确定，不能覆盖或随意重命名绕过冲突。禁止目标改名时暂停该目标；拒绝参考改名则保留原名继续，参考改名冲突也可选择原名继续。
- 理工科素材确实含历史／时事，但当前请求尚未分别选择实际存在类别；继续完整预读并集中提问，取得答案前不改名、创建最终目录或落盘最终候选；类别不明并入同次确认。
- 保存目录不明、只有附件缓存／虚拟路径、跨多个来源目录或可写性不明；在集中确认中展示实际默认及推荐绝对路径与自定义选项，等待用户决定。
- 多主题素材无法确定归属，错误合并可能损坏已有结构。
- 并发改动无法安全整合，继续写入会覆盖其他人的新内容。
- 核心图表或文档解析失败，且用户尚未决定排除它或提供替代版本。

先尝试当前环境内可行的只读方式，再具体说明需要哪份信息；不能把局部失败说成全部完成。缺少写入能力可用下载降级，但降级不能弥补原文缺失、范围选择未完成、目标身份歧义或知识冲突。仅文本环境无法做文件重命名或清理，不能声称这些操作已完成。

## 验证范围与后续评估

当前 v1.3 是规则与说明文档，完成的是静态元信息、文件结构、相互引用及规则一致性检查，没有声称已完成实际用户笔记更新、OCR／文档解析、平台安装或多阅读器渲染验证。

后续可使用经过授权、脱敏的小样例验证：目标安全规范名称、参考获准改名且字节不变／拒绝后原名继续、同名冲突不覆盖、地址歧义时先列真实候选并暂停写入、理工科历史和时事分开选择且两类均排除也保留核心技术知识、非理工科不误触发、只清理本次创建的具体中间文件；另有持续更新场景：草稿改名前后字节不变且冲突不覆盖、仅素材 D 分支能按选择生成、正式术语首次加粗且重复导入不重标、正式内容筛选保真与大纲总结不照搬、两种目标互不覆盖、重复导入无新增、同知识不同条件不误合并、大纲不会因重复素材不断膨胀、写入失败能生成包含旧全文的下载版。还可覆盖目标冲突、并发改动、扫描图表和 HTML 渲染限制。

知识数据集或 benchmark 可在后续积累，但不是当前版本依赖，本版本不附带空白数据集、评估集或未执行的测试报告。
