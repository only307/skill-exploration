## v1.2 · 2026-10-09

### 新增与调整

- 草稿、正式和大纲三类已明确识别的笔记文件名全部强制规范化；取消不规范旧名继续原位更新的机制。保护的是文件字节、正文与已有知识，不是旧文件名。纯改名前后核对完整字节，正式／大纲先改名再更新。
- 增加最终保存位置的优先级：用户指定目录 → 更新目标的唯一稳定可写目录 → 新建笔记时全部来源共同所在的唯一稳定可写目录。地址有歧义时先展示真实默认、推荐、自定义绝对路径并等待用户决定；下载交付单独报告真实生成位置或有效链接。
- 理工科来源确实包含历史或时事背景时，在任何改名、建目录或写入前分别取得实际存在类别的保留选择；四种组合均可选。背景筛选只影响新内容，不删除旧知识，不牺牲公式、条件与技术结论。
- 新增本次专用隔离临时目录与明确路径清单；完成或中止时只清理本次中间产物和空目录，不触及用户来源、最终交付或归属不明文件。无法安全清理时报告真实路径及原因。
- 同步修改 `SKILL.md`、`README.md`、`AGENT_REQUIREMENTS.md` 与本记录中的工作流、示例、能力边界、下载降级及结束反馈。

### 验证范围

- 执行技能元信息校验、四文件与相对链接检查、版本和冲突条款静态复核，并按需求中的 15 个场景推演规则结论。
- 核对 v1.0、v1.1 文件内容散列未变。本版本未执行真实笔记整理、文件改名、OCR／文档解析、下载降级或各阅读器渲染测试。

## v1.1 · 2026-10-09

### 新增与调整

- 明确正式笔记中的学术与专业术语按整篇首次出现加粗，后续不新增标识；增量补充前检查已有全文，不按素材或调用批次重新计数。
- 草稿文件名不规范时须安全规范为 `主题笔记-草稿.md`，只改名称，正文、编码、换行及完整字节不变；增加同名冲突检查与改名后的核对。
- 新增 D 分支：仅提供 PPT、照片、PDF、Word、文字等素材，也可按用户选择生成正式笔记、大纲笔记或两者，无需补交 Markdown 或创建空草稿。
- 区分仅素材生成与明确的既有笔记更新；不能读取指定旧目标时，不以 D 分支新建文件冒充更新。
- 正式笔记在保留重点、重要写法、说明和结构的基础上选择性沿用必要原句，对冗余与无关内容总结、合并或省略；禁止逐字转录整份素材后仅调整 Markdown。
- 大纲必须经模型理解和归纳后输出，禁止照搬素材段落或列表；必要术语、核心公式和定理名称可原样保留。
- 筛选与省略仅适用于新生成和新增内容，已有目标笔记的知识保护约束不变；C 分支格式整理不被强制改写。
- 同步四个文档中的分支说明、示例、能力要求及降级规则；无法本地重命名草稿时，具备原始字节读取和文件生成能力可交付规范名草稿副本，并明确原文件未改名。

### 检查范围

- 本次进行静态元信息、文件结构、相互引用、版本信息和规则一致性检查。
- 未实际执行笔记整理、草稿重命名、OCR／文档解析、下载降级或阅读器渲染，不据此声明运行正确率或兼容性。


## v1.0 · 2026-10-08

首次整理为可分享的技能文档版本。依据用户提供的原始“markdown笔记整理”规则及本次扩展要求编写；不代表存在此前已发布的版本。

### 新增

- 正式笔记、大纲笔记及两者同时生成的三种输出选项；输出选择在输入分支判断之前，已明确的选择可在同一持续任务沿用。
- 草稿、正式、大纲三文件独立机制，新文件分别采用 `主题笔记-草稿.md`、`主题笔记-正式.md`、`主题笔记-大纲.md`；不强制重命名原草稿或创建未选择的文件。
- 两种目标各自完整支持草稿输入 A、非草稿＋素材 B、仅非草稿 C，并独立执行增量更新。
- 大纲以知识点、分类、公式与关系组织，支持自查但不推断掌握度，不执行黄色解题方法荧光判定。
- 本地无法写入、但可完整读取必要内容时，使用真实文件生成能力自动降级为可下载的完整 Markdown；双模式分别交付两个文件。
- 能力要求说明，区分模型理解能力、条件相关工具能力、增强能力与不能完成的情况。

### 原始规则修正

- 区分知识内容保护、非破坏性排版与新笔记生成；已有笔记不因整理而删除知识。
- 将英文对照裁剪限定为新生成／新增文本中的冗余对照，保留已有英文及缩写、例句、论文名、公式、代码与来源标注。
- 取消“不确定也先替换原文”的做法：保留旧内容，追加有依据的纠正或绿色存疑建议，不把推测写成事实。
- 草稿目标冲突由一概拒绝调整为检查真实路径与文件身份；歧义不能安全解决时暂停受影响项并请求明确目标。
- 将“根本性读写失败直接拒绝”细分为可下载降级、可继续读取的情况和确实缺少必要输入的阻塞情况。
- 明确旧命名文件的原位更新与主题基名提取，避免生成重复“笔记”名称或把其他类型当目标。
- 对话反馈不依赖平台专属“技能调用页面”，当前对话结尾可报告新增位置、内容变化及原因；笔记内不写操作说明。

### 判定与文件安全优化

- 黄色判定保留标题和步骤线索，同时要求确有可执行指导；关键词、编号、方法历史和概念分类不单独触发，含糊内容保守不标。
- 方法块覆盖标题、步骤、关联示例及注意事项，限制到实际相关范围；绿色疑义优先，不嵌套两种颜色。
- 保留带 `display: block` 与指定背景色的 `mark` 写法，明确 HTML 内 Markdown 不保证解析，提供 HTML 子元素示例与实际阅读器验证边界。
- 去重基于全文、含义和适用条件；不误删数字、否定或公式差异，不为解决大纲膨胀删除旧内容。
- 写前读取及候选对照、重新检查外部改动、写后重读；草稿与非目标类型只读，双目标按文件报告状态。
- 不把同目录原子替换误称为并发锁或双文件事务，不虚构写入成功或下载链接。
- 图片与文档关键图表一并处理；识别歧义保留可辨识原貌与对应存疑标记，无法完整解析时不声称全部合并。
