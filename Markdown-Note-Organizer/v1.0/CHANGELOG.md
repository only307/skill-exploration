# 版本记录

## v1.0 · 2026-10-08

首次整理为可分享的技能文档版本。依据用户提供的原始“markdown笔记整理”规则及本次扩展要求编写；不代表存在此前已发布的版本。

### 新增

- 正式笔记、大纲笔记及两者同时生成的三种输出选项；输出选择在输入分支判断之前，已明确的选择可在同一持续任务沿用。
- 草稿、正式、大纲三文件独立机制，新文件分别采用 `主题笔记-草稿.md`、`主题笔记-正式.md`、`主题笔记-大纲.md`；不强制重命名原草稿或创建未选择的文件。
- 两种目标各自完整支持草稿输入 A、非草稿＋素材 B、仅非草稿 C，并独立执行增量更新。
- 大纲以知识点、分类、公式与关系组织，支持自查但不推断掌握度，不执行黄色解题方法荧光判定。
- 本地无法写入、但可完整读取必要内容时，使用真实文件生成能力自动降级为可下载的完整 Markdown；双模式分别交付两个文件。
- 能力要求说明，区分模型理解能力、条件相关工具能力、增强能力与不能完成的情况。

### 原始规则修正

- 区分知识内容保护、非破坏性排版与新笔记生成；已有笔记不因整理而删除知识。
- 将英文对照裁剪限定为新生成／新增文本中的冗余对照，保留已有英文及缩写、例句、论文名、公式、代码与来源标注。
- 取消“不确定也先替换原文”的做法：保留旧内容，追加有依据的纠正或绿色存疑建议，不把推测写成事实。
- 草稿目标冲突由一概拒绝调整为检查真实路径与文件身份；歧义不能安全解决时暂停受影响项并请求明确目标。
- 将“根本性读写失败直接拒绝”细分为可下载降级、可继续读取的情况和确实缺少必要输入的阻塞情况。
- 明确旧命名文件的原位更新与主题基名提取，避免生成重复“笔记”名称或把其他类型当目标。
- 对话反馈不依赖平台专属“技能调用页面”，当前对话结尾可报告新增位置、内容变化及原因；笔记内不写操作说明。

### 判定与文件安全优化

- 黄色判定保留标题和步骤线索，同时要求确有可执行指导；关键词、编号、方法历史和概念分类不单独触发，含糊内容保守不标。
- 方法块覆盖标题、步骤、关联示例及注意事项，限制到实际相关范围；绿色疑义优先，不嵌套两种颜色。
- 保留带 `display: block` 与指定背景色的 `mark` 写法，明确 HTML 内 Markdown 不保证解析，提供 HTML 子元素示例与实际阅读器验证边界。
- 去重基于全文、含义和适用条件；不误删数字、否定或公式差异，不为解决大纲膨胀删除旧内容。
- 写前读取及候选对照、重新检查外部改动、写后重读；草稿与非目标类型只读，双目标按文件报告状态。
- 不把同目录原子替换误称为并发锁或双文件事务，不虚构写入成功或下载链接。
- 图片与文档关键图表一并处理；识别歧义保留可辨识原貌与对应存疑标记，无法完整解析时不声称全部合并。
