# skill‑exploration
> 南开大学 lyf 的 Skill‑Exploration 仓库。本仓库存放个人探索的AI技能集合，包含自制实现、多技能路由编排、第三方搜集引用三类内容。

- ✅ **根目录下直接放置的 Skill：属于本人自制实现，可以直接自用。**
- `./skills_plugins/collected_skills_plugins`：搜集整理的第三方技能。仅供个人学习自用，使用前请查阅上游 License。
- `./skills_plugins/skill_router_orchestration`：上游技能进行串联路由编排后的组合方案。仅供个人学习自用，使用前请查阅上游 License。

## 主要项目目录说明
1. `./Markdown‑Note‑Organizer`
> Markdown笔记整理技能；接收草稿、PPT、图片、PDF、Word素材，完成正式Markdown笔记、大纲笔记的整理与增量更新。
2. `./skills_plugins/skill_router_orchestration/document‑conversion‑router`
> 文件格式互转路由编排；支持 PDF、Word、Markdown 的互相转换。基于上游开源免费技能组合实现；也可直接访问 [https://www.ilovepdf.com/](https://www.ilovepdf.com/)。尚未完成完整能力对比测试。
